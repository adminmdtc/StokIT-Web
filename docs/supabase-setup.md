# คู่มือใช้ Supabase เป็นฐานข้อมูลคลาวด์ (ฟรี)

ทำตามครั้งเดียว ใช้เวลาประมาณ 5 นาที จากนั้นข้อมูลจะอยู่บนคลาวด์ เปิดจากเครื่องไหนก็เห็นข้อมูลชุดเดียวกัน ไม่ต้องเปิดคอมเซิร์ฟเวอร์ทิ้งไว้เลย

## 1. สมัคร Supabase

1. เปิดเว็บ https://supabase.com → กด **Start your project** → สมัครด้วย GitHub หรืออีเมลก็ได้
2. กด **New project** ตั้งชื่อ เช่น `it-stock` ตั้งรหัสผ่าน Database Password (ใช้ภายในหน้า Supabase เท่านั้น ไม่เกี่ยวกับแอป) เลือก Region **Singapore** → กด **Create new project** แล้วรอ 1–2 นาที

## 2. สร้างตาราง

1. ในแอป IT Stock → เมนู **ฐานข้อมูล** → เลือก **Supabase Cloud** → กดปุ่ม **ดู SQL สร้างตาราง** → กด **คัดลอก SQL**
2. กลับที่เว็บ Supabase → เมนูซ้าย **SQL Editor** → **New query** → วางคำสั่งทั้งหมด → กด **Run**
3. ขึ้น `Success. No rows returned` = สำเร็จ (จะมีตาราง `it_items`, `it_transactions`, `it_users`, `it_reorder`, `it_meta` ในเมนู Table Editor)

## 3. เอา URL กับ anon key มากรอกในแอป

1. ที่เว็บ Supabase → ⚙️ **Project Settings** → **API**
2. คัดลอก 2 ค่า:
   - **Project URL** เช่น `https://abcdefgh.supabase.co`
   - **anon public** key (ขึ้นต้น `eyJ...` ยาว ๆ)
3. กลับที่หน้าต่างตั้งค่าฐานข้อมูลในแอป → โหมด **Supabase Cloud** → กรอกทั้ง 2 ค่า → ติ๊ก **เปิดใช้งานการซิงค์** → กด **ทดสอบ การเชื่อม ฐาน ข้อมูล** ให้ขึ้น ✅ → กด **บันทึก**
4. ครั้งแรกคลาวด์ยังว่าง แอปจะ**อัปโหลดข้อมูลในเครื่องขึ้นคลาวด์ให้อัตโนมัติ** — จากนั้นเครื่องอื่นก็เปิดโหมด Supabase ด้วย URL/key เดียวกัน แล้วเลือก **ดึงข้อมูลจากคลาวด์** ได้เลย

## การทำงานหลังตั้งค่าเสร็จ

- เพิ่ม/แก้ไข/ลบ วัสดุ รับเข้า จำหน่าย ผู้ใช้ → ส่งขึ้นคลาวด์ทันทีทุกรายการ
- เครื่องอื่นที่เปิดโหมด Supabase ด้วย key เดียวกัน กด **โหลด** / **บันทึก** เพื่อดึงข้อมูลล่าสุด
- ยังเก็บสำเนาในเครื่องทุกเครื่องเหมือนเดิม — เน็ตหลุดก็ทำงานต่อได้ พอเน็ตกลับมาข้อมูลใหม่จะถูกส่งขึ้นเมื่อมีการบันทึกครั้งถัดไป

## คำถามที่พบบ่อย

**ติด error "ยังไม่ได้สร้างตาราง"** → ข้ามขั้นตอนที่ 2 ไป กลับไปรัน SQL ใน SQL Editor ก่อน

**ติด error "API key ไม่ถูกต้อง"** → ต้องใช้ key ที่ชื่อ `anon` `public` เท่านั้น (ห้ามใช้ `service_role` ในเว็บสาธารณะ)

**ปลอดภัยไหม** → URL + anon key ถือเป็นกุญแจบ้าน ใครมีก็อ่าน/แก้ข้อมูลได้ จึงให้กรอกเองในแอป (เก็บในเครื่องผู้ใช้ ไม่ฝังในโค้ด) และควรเปิด **Row Level Security** ตาม SQL ที่ให้ไว้ ถ้า key หลุดให้ไปที่ Project Settings → API → **Rotate anon key** แล้วเปลี่ยนในแอปทุกเครื่อง

**ใช้พร้อมกันหลายคน** → ได้ แต่ถ้า 2 คนแก้รายการเดียวกันพร้อมกัน คนที่กดบันทึกทีหลังจะทับคนแรก (แบบเดียวกับ Google Sheets ที่ไม่รีเฟรช) แนะนำให้กด "โหลด" ก่อนแก้ข้อมูลสำคัญ

## สลับกลับไปใช้ MySQL Server เดิม

หน้าต่างเดิม → เลือก **MySQL Server (เครือข่ายภายใน)** → กรอก IP server → กดบันทึก แอปจะใช้ MySQL ทันที (โหมดทั้งสองเก็บค่าไว้แยกกัน สลับไปมาได้โดยข้อมูลไม่หาย)
